# Security Policy

## Supported versions

No release has been published yet. Once one is, security fixes go to the latest release line,
and this table names it.

## Reporting a vulnerability

Please **do not** open a public issue, pull request or discussion for security vulnerabilities.

Report privately through GitHub:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability** to open a private security advisory.

Please include, where possible: a description and its impact, steps to reproduce or a proof of
concept, and the affected version, commit or endpoint.

## What to expect

- We aim to acknowledge new reports within a few business days.
- We keep you updated on the assessment and the fix.
- Once a fix is available, we coordinate disclosure and credit you if you wish.

Thank you for helping keep Octoreview PHP SDK and its users safe.
